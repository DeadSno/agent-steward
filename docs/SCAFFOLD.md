# Scaffolding из gate-passed рецептов (Деталь 3.19 / S-6)

Одна команда создаёт минимальный проект из рецепта, который уже прошёл
объективный гейт. Рецепт берётся из библиотеки [RECIPES.md](RECIPES.md);
до записи он повторно проверяется `verifyRecipe()`, поэтому «пример ради
примера» в свежий чек-аут не попадёт.

<a id="methodology"></a>

## Использование

```sh
agent-steward scaffold open-spec --out ./my-project
agent-steward scaffold capability-router --out ./my-project --json
agent-steward scaffold reliability-scorecard --out ./my-project --force
```

Публичный API из `agent-steward/core`:

```js
import { scaffoldFromRecipe, scaffoldFromRecipeId } from "agent-steward/core";
const result = scaffoldFromRecipeId("open-spec", "./my-project");
```

Exit-коды CLI: `0` — проект создан, `1` — рецепт не найден/не прошёл
проверку или файлы уже существуют, `2` — неверные аргументы (нет `--out`).

## Создаваемые файлы

| Файл | Содержание |
|---|---|
| `opencode.pipeline.yaml` | Pipeline YAML рецепта без изменений |
| `README.md` | Описание рецепта, таблица доказательств гейтов, команды проверки, методика |
| `verify-gates.mjs` | Автономный прогон команд гейтов через `child_process` (без БД и плагина) |

`includeGateScript: false` отключает создание `verify-gates.mjs`.

## Правила безопасности

- До записи рецепт обязан пройти `verifyRecipe()`: все объявленные гейты
  имеют доказательства `objective/passed`, команды совпадают с `qualityGate`,
  даты корректны, а шаги pipeline без доказательства отклоняются.
- Существующие файлы не перезаписываются. Нужна явная опция `overwrite: true`
  или флаг `--force` — так scaffolding не уничтожит пользовательские правки.
- Путь назначения создаётся рекурсивно; результат содержит абсолютный путь и
  отсортированный список записанных файлов.
- В сгенерированных файлах нет текущего времени: одинаковый рецепт даёт
  побайтово одинаковый результат (проверяется тестом детерминизма).

## Честное ограничение

Доказательства гейтов — снимок объективного прогона на момент публикации
рецепта, а не гарантия работоспособности на текущей машине. `verify-gates.mjs`
заново запускает команды, но без установленных зависимостей прогон может
упасть: это отсутствие окружения, а не опровержение рецепта. Scaffolding
не копирует реальные результаты прогонов и не делает вид, что гейты
перепроверены.
