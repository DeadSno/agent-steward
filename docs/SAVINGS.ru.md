# Счётчик «сэкономлено $»

Дашборд и `get_analytics` показывают KPI **«Сэкономлено»**. Это **оценка**, а не
бухгалтерский факт: рядом с суммой стоит пометка «оценка» и ссылка на эту
страницу.

Translations: [English](SAVINGS.md) · [中文](SAVINGS.zh.md)

## Methodology

Контрфактика строится по истории запусков (`history` в SQLite).

1. Берутся записи окна анализа, кроме незавершённых (`status = "running"`).
2. В оценку попадает запуск, у которого **есть токены** (`tokens > 0`) и
   **не записана стоимость** (`costUsd` пустой или `0`). Обычно это локальная
   модель (Ollama) или уже оплаченная подписка: токены потрачены, но деньги за
   них не списаны.
3. Для каждого такого запуска считается гипотетическая облачная стоимость:

   ```
   saved = tokens / 1000 × referenceCostPer1kTokensUsd
   ```

4. Сумма складывается по всем запускам окна и разбивается по задачам
   (топ-10 по экономии).

Эталонная цена по умолчанию — **$0.01 за 1k токенов** (смесь входа и выхода
облачного провайдера среднего класса), константа
`CLOUD_REFERENCE_COST_PER_1K_TOKENS_USD` в `src/core/savings.ts`. Запуски с
записанной стоимостью в экономию не попадают: за них деньги уже списаны, и
сравнивать нечего.

## Что оценка не учитывает

- кеш промптов, скидки и пакетные тарифы;
- разницу цен входных и выходных токенов;
- запуски без токенов (например, чистый shell): экономии там может и не быть;
- запуски, где стоимость не записана по ошибке, а не потому что она нулевая —
  такие записи завышают оценку.

Поэтому счётчик отвечает на вопрос «сколько бы это стоило в облаке по
эталонной цене», а не «сколько денег вернулось на счёт».

## What-If: модели и цены

Блок дашборда «если бы все запуски шли через модель X» больше не опирается на
захардкоженный список. И список, и цены берутся из самого OpenCode:

1. **Доступные модели** — `opencode models`, то есть ровно то, что настроено
   на этой машине (провайдеры, ключи, локальные модели Ollama). Первыми идут
   модели, которые уже встречались в истории запусков, дальше — по одной
   модели на каждую цену (самая дешёвая, средняя, самая дорогая). Всего не
   больше пяти строк.
2. **Цены** — каталог models.dev, который OpenCode держит в
   `<cache>/opencode/models.json` (`cost.input` / `cost.output`, USD за 1M
   токенов). История не делит токены на входные и выходные, поэтому берётся
   среднее из двух цен.

Порядок выбора цены: `OPENCODE_SCHEDULER_MODEL_PRICES` (JSON) → каталог
OpenCode → встроенная таблица → 3 $ за 1M токенов. Локальные провайдеры
(Ollama, LM Studio) и модели `*-free` считаются бесплатными.

| Переменная | Значение |
| --- | --- |
| `OPENCODE_SCHEDULER_WHAT_IF_MODELS` | явный JSON-список, заменяет подбор |
| `OPENCODE_SCHEDULER_MODEL_PRICES` | явные цены, например `{"openai/gpt-4o": 2.5}` |
| `OPENCODE_SCHEDULER_MODELS_CACHE` | путь к другому `models.json` |
| `OPENCODE_SCHEDULER_MODEL_SOURCE=static` | не обращаться к OpenCode, только встроенные значения |

Если OpenCode недоступен, блок откатывается на встроенный список и цены —
дашборд продолжает работать.

## API

`get_analytics` возвращает `report.savings`:

| Поле | Значение |
| --- | --- |
| `kind` | всегда `estimate` |
| `savedUsd` | оценка экономии, USD |
| `runs` | запусков в контрфактике |
| `tokens` | токенов в этих запусках |
| `actualCostUsd` | записанная стоимость этих же запусков (обычно 0) |
| `totalCostUsd` | записанная стоимость всех запусков окна |
| `referenceCostPer1kTokensUsd` | эталонная цена |
| `methodologyUrl` | ссылка на эту страницу |
| `byTask` | разбивка `{ taskName, runs, tokens, savedUsd }` |

Методика проверяется на фиксированных данных: `test-savings.mjs`, 14 проверок.
