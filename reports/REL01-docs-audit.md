# REL-01 — аудит счётчика сюит в переведённых README

Дата: 2026-11-20

## Найденное расхождение

Эталоны из кода: **30** MCP-инструментов, **57** RPC-методов, **115** уникальных сюит в `npm test`
(115 вызовов `node test-*.mjs`, дубликатов нет; эталон в `test-docs.mjs` — `suitesInScriptUnique.length`).
Корневой `README.md` уже содержал `npm test # 115 test suites, 600+ checks`, а переведённые версии
отставали на 32 сюита:

| Файл | Было | Стало |
| --- | --- | --- |
| `docs/README.ru.md:265` | `npm test             # 83 сюит, 600+ проверок` | `npm test             # 115 сюит, 600+ проверок` |
| `docs/README.zh.md:273` | `npm test             # 83 test suites, 600+ checks` | `npm test             # 115 test suites, 600+ checks` |

Причина дрейфа: счётчик обновлялся в корневом `README.md` и в локальных `SKILL.md`, но не в
переведённых README. Существовавшая проверка в `test-docs.mjs` сверяла только корневой `README.md`,
поэтому расхождение в локалях не детектировалось.

## Список изменённых файлов

- `docs/README.ru.md` — `83` → `115` в строке `npm test`; остальной текст и форматирование сохранены.
- `docs/README.zh.md` — `83` → `115` в строке `npm test`; остальной текст и форматирование сохранены.
- `test-docs.mjs` — сразу после существующей проверки счётчика сюит добавлен цикл проверки
  `docs/README.ru.md` и `docs/README.zh.md`. Число извлекается из строки `npm test … # N`,
  ожидаемое значение берётся из уже вычисленной переменной `suitesInScriptUnique.length` (без
  хардкода). Сообщение при расхождении: `<файл>: счётчик сюит в npm test найдено N, ожидалось M`;
  если число отсутствует (или файл не читается): `<файл>: счётчик сюит в npm test отсутствует,
  ожидалось M`.
- `CHANGELOG.md` — одна запись REL-01 в разделе `[Unreleased] → Fixed`.
- `reports/REL01-docs-audit.md` — настоящий отчёт.

Новые `test-*.mjs` не создавались. Файлы вне SCOPE не изменялись: после `npm run build`
`git status --short` показывал только `docs/README.ru.md`, `docs/README.zh.md`, `test-docs.mjs`
(на момент написания отчёта добавлены `CHANGELOG.md` и настоящий отчёт).

## Устранение дрейфа

В `test-docs.mjs` проверка использует тот же эталон, что и проверка корневого README и счётчиков
в `SKILL.md` — `suitesInScriptUnique.length`. При добавлении новой сюиты в `npm test` ожидаемое
число обновится автоматически, и если переводы не поспеют за ним, тест упадёт с указанием файла,
найденного и ожидаемого значений.

## Команды проверки и результаты

| Команда | Результат |
| --- | --- |
| `node test-docs.mjs` | exit 0, `Docs: 129/129 проверок пройдено.` (включая 2 новые проверки локалей) |
| `node test-workflows.mjs` | exit 0, `Все проверки пройдены (workflows): 141/141.` |
| `npm run build` | exit 0, `tsc` без ошибок |

Новые строки в выводе `test-docs.mjs`:

```
OK   docs/README.ru.md: счётчик сюит в npm test найдено 115, ожидалось 115
OK   docs/README.zh.md: счётчик сюит в npm test найдено 115, ожидалось 115
```

## Проверка отрицательного пути

Чтобы убедиться, что проверка действительно ловит дрейф, оба README временно мутировались на диске
(с сохранением точной копии и восстановлением в `finally`):

| Мутация | Результат |
| --- | --- |
| `docs/README.ru.md`: `115` → `83` | `FAIL docs/README.ru.md: счётчик сюит в npm test найдено 83, ожидалось 115` |
| `docs/README.zh.md`: число удалено | `FAIL docs/README.zh.md: счётчик сюит в npm test отсутствует, ожидалось 115` |

Оба провала в одном прогоне: exit code `1`. После восстановления исходного содержимого
повторный `node test-docs.mjs`: exit 0, `Docs: 129/129 проверок пройдено.` Файлы восстановлены
побайтово из резервных копий.

## Итог

Расхождение устранено, автоматическая проверка добавлена и подтверждена на позитивном и
негативном прогонах. Коммит и push не выполнялись — это делает afterScript обёртки.
