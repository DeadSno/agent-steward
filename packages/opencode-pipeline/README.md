# opencode-pipeline — reserved name

This package name is reserved for a possible future rename of
[**opencode-windows-scheduler**](https://www.npmjs.com/package/opencode-windows-scheduler).

**There is no code here yet.** Install the real package:

```bash
npm install opencode-windows-scheduler
```

`opencode-windows-scheduler` is a free, MIT-licensed OpenCode plugin for scheduling
and orchestrating AI agent jobs: cron and one-shot runs, DAG pipelines, matrix
builds, quality gates, SQLite history, metrics and a local web dashboard.
Works on Windows, macOS and Linux.

- Repository: <https://github.com/DeadSno/opencode-windows-scheduler>
- Documentation: <https://github.com/DeadSno/opencode-windows-scheduler/tree/main/docs>
- Changelog: <https://github.com/DeadSno/opencode-windows-scheduler/blob/main/CHANGELOG.md>

If the rename ever happens, this package will become a thin re-export and the
old package will keep working. Until then, treat this name as a placeholder.
